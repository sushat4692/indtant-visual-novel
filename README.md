# Instant Visual Novel

ブラウザだけで動く、ビジュアルノベル / アドベンチャーゲーム作成・再生プラットフォームです。

- 規定の背景・キャラクター画像・エフェクトをプラットフォーム側が用意（SVG/CSS でその場生成、画像ファイル同梱なし）
- 特定フォーマットのテキスト（独自のシーン記述 DSL）を流し込むと再生される
- 作成したノベルをエクスポート / インポートして共有できる
- データはサーバーに保存せず、ブラウザ内（IndexedDB / localStorage）に保存

## 技術スタック

React 19 + TypeScript + Vite + Tailwind CSS 4 + TanStack Router。暗号化は WebCrypto のみで実装。

```bash
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # 型チェック + 本番ビルド
npm run test     # パーサ / ランタイム / 暗号のユニットテスト
```

## 構成

ノベルは **シーン単位** で分割され、シーン間を **ジャンプ / 選択肢** で分岐します。

- **プレイヤー**（`/play/:id`）: 全画面でノベルを再生。クリック / タップで進行、選択肢で分岐。
- **エディタ**（`/editor/:id`）: 左にシーン一覧・キャラクター・アセット、中央に DSL エディタ、右にライブプレビュー。
- **ホーム**（`/`）: プロジェクト一覧、新規作成、削除、インポート（ドラッグ&ドロップ）。

## シーン記述 DSL

1 行 1 コマンド。`#` 始まりはコメント、空行は無視されます。

```
# 放課後の教室
bg bg_classroom              # 背景を変更（アセットID）
show hanako center           # キャラを表示（left | center | right）
hanako: あれ、太郎くん。      # 「キー: セリフ」でセリフ
: 二人は見つめ合った。         # 先頭がコロンだけなら地の文（ナレーション）
@shake                       # 画面エフェクト（shake / flash / fade / fadeout）
bgm bgm_calm                 # BGM（任意・アップロード音声ID）
wait 500                     # 待機（ms）
hide taro                    # キャラを隠す
-> 告白する : confess         # 選択肢（連続する -> は1つのメニューにまとまる）
-> ごまかす : dodge
jump next_scene              # 無条件ジャンプ
end                          # 終了
```

新しい表現を増やすのは簡単です。`src/engine/commands/` に
`{ name, match, parse }` を実装したファイルを追加し、`commands/index.ts`
のレジストリに登録するだけで、パーサ／ランタイムに新コマンドが組み込まれます
（将来の変数・条件分岐などもこの仕組みで拡張できます）。

## アセット

- **組み込みアセット**: 背景（教室・部屋・街・夕焼け・空・夜）、キャラ立ち絵（男女×2色）を
  SVG データURLとして同梱。`src/assets/builtinRegistry.ts` 参照。
- **アップロード**: エディタの「画像アップロード」から背景 / 立ち絵を追加でき、IndexedDB に保存。
  DSL では割り当てられたアセットID（`up_xxxxxxxx`）で参照します。

## エクスポート / インポート

エディタの「エクスポート」から 2 種類の出力を選べます。

| モード | ファイル | 内容 |
| --- | --- | --- |
| 編集可（平文） | `*.vnproj.json` | インポートするとエディタで編集できる |
| 編集不可（暗号化） | `*.vnplay.json` | パスワードで暗号化。**再生専用**で取り込まれ、エディタでは開けない |

暗号化は WebCrypto の AES-GCM + PBKDF2 を使用します。

> ⚠️ ブラウザ内で再生・復号する性質上、暗号化は完全な DRM ではありません。
> パスワードを知っている人（＝プレイヤー）には最終的に内容が渡ります。
> 目的は、配布者が意図しない再編集・抜き取りを抑止することです。

インポートはホーム画面へのドラッグ&ドロップ、または「インポート」ボタンから行います。

## ディレクトリ

```
src/
  engine/        DSL パーサ・ランタイム・検証・コマンドレジストリ
  components/    ステージ描画 (StageView 他) とエディタ用 UI
  assets/        組み込みプレースホルダ（SVG生成）レジストリ
  storage/       IndexedDB（プロジェクト / アップロード画像）
  share/         エクスポート/インポート、バンドル化、暗号化
  router.tsx     TanStack Router のルート定義（型安全なルートツリー）
  routes/        Home / Editor / Player ページ
  data/          初回シードのサンプルプロジェクト
```
